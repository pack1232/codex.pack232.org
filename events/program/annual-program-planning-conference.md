# Annual Program Planning Conference

Annual meeting to set the pack's program calendar for the coming Scouting year. The conference sets pack meeting dates, monthly themes, major events, and assigns activity coordinators. All den leaders should attend.

## Timeline / Checklist

| When | Task |
|---|---|
| June | Cubmaster and Committee Chair set the conference date |
| July/August | Hold the planning conference |
| At the conference | Set pack meeting dates for the year |
| At the conference | Assign monthly themes and program activities |
| At the conference | Identify major event dates (Pinewood Derby, Blue & Gold, etc.) |
| At the conference | Assign activity coordinators for each event |
| After the conference | Distribute the finalized calendar to all families |

## Roles Involved

- **Cubmaster** -- leads the planning conference
- **Committee Chair** -- coordinates logistics and budget considerations
- **Den Leaders** -- provide input on den schedules and program needs
- **Assistant Cubmaster** -- supports planning and fills gaps
- **Program Chair** -- assists with calendar coordination
