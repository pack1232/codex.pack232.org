# School-Night Recruitment Event

Pack 232's primary annual Scout recruitment event, held at Glenmont Elementary. The Cubmaster presents the Cub Scout program to prospective families, and families can sign up on the spot. Follow up with all interested families within 48 hours.

## Timeline / Checklist

| When | Task |
|---|---|
| August | Prepare recruitment materials (fliers, sign-up forms, info packets) |
| August | Coordinate with Glenmont Elementary for event permission and facility access |
| September | Host the school-night event |
| Within 48 hours | Follow up with all interested families |

## Venue & Logistics

Held at **Glenmont Elementary**. Coordinate with the school administration for room access, setup, and any required approvals.

## Roles Involved

- **Membership Chair** -- organizes the event and manages follow-up
- **Cubmaster** -- presents the Cub Scout program to prospective families
- **Den Leaders** -- attend in uniform to answer questions and represent their dens
