## What is the Codex?

The Codex is a self-contained reference for Pack 232 volunteers. Each role has its own folder with a README covering core responsibilities, requirements, and key contacts. Sub-files provide deeper guidance on specific tasks.

**New to a role?** Start with [All Roles](roles/) and find your position. Your role's README has everything you need to get started.

**Looking for pack-wide info?** Check the [shared resources](roles/_shared/) for training requirements, BSA policies, and the annual calendar.
