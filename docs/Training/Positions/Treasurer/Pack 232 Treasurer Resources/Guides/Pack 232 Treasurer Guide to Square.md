Reconciling Square

NOTE: This should be done before reconciling the SEFCU account so that those transactions have something to match against.

Login to Quickbooks and go to Banking > App Transactions.
Transactions are brought in at the deposit level and the deposit info to the SEFCU account and corresponding fees come in pretty well automatically.
Open each transaction to view the individual transactions (sales) associated with that deposit. For each:
Click to open the transaction sales detail.
Select the appropriate customer to attribute the sale to and Save
Select the appropriate products/services and save each.
Click Done when all have been categorized and continue with any other transactions associated with that deposit.
You can click the link to view the transaction in Square right from within Quickbooks for more information. I find using the Square Orders page and the information given from that to be more helpful.

NOTE: Because of the delay in deposits (not immediately, batched to save processing fees), there is often a delay between when a transaction happens and when it syncs to quickbooks.
