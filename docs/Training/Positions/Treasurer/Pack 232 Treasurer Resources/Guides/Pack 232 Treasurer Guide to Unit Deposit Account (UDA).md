# Overview
Council maintains an account that we can deposit money into and then use to pay fees.
# Accessing the Account
Sandy Elkins provided Josh McWilliam the following video on how to manage this in mid March 2022 and that is likely the best resource on how to use the Unit Deposit Account (UDA) within BlackPub:

https://www.youtube.com/watch?v=VpAt-E-eniI

Other BlackPug tutorials if you have no idea of what I am even talking about.

The gist of it is as follows:

Go to the Twin Rivers Council site and select “Black Pug Login Page” under “Volunteer Resources” in the top menu: https://trcscouting.org/
Select the Pack from the dropdown in the upper right and then from the same dropdown select “View Activity”
Then select “Unit Account” tab.
# Reconciling the Account in Quickbooks
Note that within Quickbooks Online there is a “Council UDA” account that we use to track deposits to this account and expenditures from it. There is also a Payment method of the same name setup as well that can be used.

# Using Funds from The Account
Some checkout features within various systems (likely just BlackPub) may allow you to use this as a payment method.

The most common way to use it in the past though have been for paying for things like adult or event registrations when these were managed via email communications with council. In the past we might have sent an application via email and they would tell us we owed money and we (Treasurer or Chair) would authorize them to use the UDA to pay the fee.

However, as application process for adults moves to their online system (definitely the better way to go now) and we properly use BlackPug to do event registrations, I’m not sure there is a good use case for the UDA and thus we may end up no longer using it. We would certainly prefer to have funds sitting in our own accounts building interest.
