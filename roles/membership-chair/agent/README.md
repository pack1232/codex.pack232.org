# Membership Chair Agent

## Agent Purpose

The Membership Chair agent is designed to help with recruitment event planning, new family onboarding materials, retention outreach, and membership communications.

---

## Available Skills

*(To be populated as skills are built)*

- Recruitment event planning checklist
- New family welcome package generator
- Dropout follow-up email drafter
- Orientation meeting agenda builder

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Planning a school-night recruitment event
- Drafting a welcome email for a new Scout family
- Creating a new family orientation agenda
- Writing a follow-up message to a family that has missed several events
- Generating a family talent survey form
