# Misc. Pack Activities Coordinator

## Role Summary

The Misc. Pack Activities Coordinator handles pack-organized events and outings that don't fall under another coordinator's scope — one-off outings, special theme nights, family fun events, field trips, and other activities that aren't covered by the camping, derby, or service coordinators.

## Reports To

| Relationship | Role |
|---|---|
| Reports to | Program Chair |
| Works with | Cubmaster, Treasurer, Equipment Coordinator |

## Core Responsibilities

- Plan and coordinate pack activities that aren't assigned to a specific coordinator
- Examples: bowling night, skating party, museum visit, fishing derby, movie night, Caroling
- Handle event logistics: venue reservation, headcount, fee collection, supplies
- Communicate event details to families
- Ensure BSA safety compliance (SAFE Checklist, two-deep leadership, health forms)
- Coordinate with the Cubmaster on how activities fit into the overall pack program
- Recruit parent volunteers to help run events

## Key Dates / Timeline

| When | Task |
|---|---|
| September | Work with Cubmaster and Program Chair to identify misc. events for the year |
| As scheduled | Plan and execute each event |
| After each event | Gather feedback; submit receipts to Treasurer |
