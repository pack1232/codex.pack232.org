# Misc. Council Activities Coordinator

## Role Summary

The Misc. Council Activities Coordinator manages Pack 232's participation in Twin Rivers Council-organized events and activities that don't fall under another coordinator's scope — things like ValleyCats Scout Night, Council Camporees, district events, and other council-sponsored programs.

## Reports To

| Relationship | Role |
|---|---|
| Reports to | Program Chair |
| Works with | Cubmaster, Treasurer |

## Core Responsibilities

- Monitor the Twin Rivers Council calendar for events the pack may want to participate in
- Communicate council event opportunities to pack families
- Coordinate group registration and ticket purchases for council events (e.g., ValleyCats Scout Night)
- Handle logistics: transportation, headcount, fee collection (coordinate with Treasurer)
- Represent the pack at district- or council-level planning meetings for these events when needed
- Report back to the Program Chair and Cubmaster on upcoming opportunities

## Key Dates / Timeline

| When | Task |
|---|---|
| Year-round | Monitor council calendar; bring opportunities to committee |
| As scheduled | Coordinate registration, tickets, and logistics for each event |
| After each event | Gather feedback; note improvements for next time |
