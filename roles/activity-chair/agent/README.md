# Activities Chair Agent

## Agent Purpose

The Activities Chair agent is designed to help with event planning, safety checklists, family communications, and logistics for pack activities and camping trips.

---

## Available Skills

*(To be populated as skills are built)*

- Event planning checklist generator
- SAFE Checklist template
- Family event communication drafter
- Camping packing list generator

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Building a planning checklist for a specific upcoming event
- Generating a SAFE Checklist for a proposed activity
- Drafting a family communication with event logistics and what to bring
- Creating a camping packing list appropriate for the season and Scout age
- Planning the activity calendar for the upcoming year
