# Webmaster

## Role Summary

The Webmaster manages the Pack 232 website (pack232.org), keeping it current with event information, contact details, and resources for pack families. The website is often the first thing prospective families see when learning about the pack.

## Reports To

| Relationship | Role |
|---|---|
| Reports to | Secretary |
| Works with | Public Relations Coordinator, Membership Chair, Committee Chair |

## Core Responsibilities

- Keep pack232.org updated with current event schedules, meeting times, and locations
- Post event registration pages and coordinate with Treasurer on WooCommerce payment integration
- Maintain the leadership contact page with current role holders and email addresses
- Ensure the site is mobile-friendly and easy to navigate for new families
- Update photo galleries (with appropriate photo consent) after major events
- Coordinate with the Secretary on communications that reference the website
- Manage website hosting, domain renewal, and technical maintenance
- Ensure the website complies with BSA branding guidelines

## Key Dates / Timeline

| When | Task |
|---|---|
| August | Update site for new program year (calendar, leaders, den info) |
| Before each event | Post event details and registration links |
| After each event | Update galleries, post recaps if applicable |
| December | Verify domain renewal; update for recharter changes |
