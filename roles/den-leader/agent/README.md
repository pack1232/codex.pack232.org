# Den Leader Agent

## Agent Purpose

The Den Leader agent is designed to help den leaders plan meetings, track advancement, prepare for pack meeting participation, and communicate with den families.

---

## Available Skills

*(To be populated as skills are built)*

- Den meeting planner (by rank and adventure)
- Advancement tracker / status checker
- Pack meeting participation prep
- Family communication drafter

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Planning a den meeting for a specific adventure and rank
- Checking which Scouts have completed which requirements
- Drafting a reminder to families about an upcoming den meeting or event
- Preparing your den's assignment for the upcoming pack meeting (flag ceremony, skit, etc.)
- Writing a den family newsletter or monthly update
