# Treasurer Agent

## Agent Purpose

The Treasurer agent is designed to help with financial reporting, budget planning, reconciliation, and family payment communications.

---

## Available Skills

*(To be populated as skills are built)*

- Monthly financial report generator
- Budget template builder
- Payment status checker (who paid / who owes)
- Reimbursement request processor
- Popcorn accounting reconciliation

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Generating a monthly financial report for the committee meeting
- Building or updating the annual budget
- Checking who has paid for a specific event
- Drafting a payment reminder to families
- Reconciling popcorn sale proceeds
- Calculating Scout account balances
