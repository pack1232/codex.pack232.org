# Assistant Cubmaster Agent

## Agent Purpose

The Assistant Cubmaster agent is designed to help coordinate den chief activities, support den leaders, and assist with pack meeting preparation and recruitment.

---

## Available Skills

*(To be populated as skills are built)*

- Den chief planning meeting agenda
- Recruitment support materials
- Pack meeting run-of-show support

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Drafting a den chief planning meeting agenda
- Coordinating den leader check-ins before a pack meeting
- Preparing recruitment event talking points
- Planning logistics for a specific pack activity
