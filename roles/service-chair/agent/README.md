# Service Chair Agent

## Agent Purpose

The Service Chair agent is designed to help with service project ideation, planning, family communication, and service hour recording.

---

## Available Skills

*(To be populated as skills are built)*

- Service project idea generator
- Project planning checklist
- Family service event communication drafter
- Service hour report generator

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Brainstorming service project ideas appropriate for Cub Scout-age youth
- Building a planning checklist for a specific service event
- Drafting a family communication about an upcoming service project
- Generating a service hour report for submission to the Committee Chair
- Writing a post-event thank-you note to the service project beneficiary
