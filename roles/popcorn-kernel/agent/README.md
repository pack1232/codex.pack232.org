# Popcorn Kernel Agent

## Agent Purpose

The Popcorn Kernel agent is designed to help with sale planning, Show and Sell scheduling, family communications, and end-of-season accounting.

---

## Available Skills

*(To be populated as skills are built)*

- Sale season checklist generator
- Show and Sell sign-up scheduler
- Family kickoff communication drafter
- Scout sales tracker
- End-of-season accounting summary

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Creating a sale kickoff communication to families
- Building a Show and Sell schedule and sign-up
- Drafting a reminder to families about upcoming order deadlines
- Calculating Scout account credits based on sales data
- Summarizing the season's results for the committee
