# Marketing Chair Agent

## Agent Purpose

The Marketing Chair agent is designed to help with social media content drafting, press release writing, event promotion, and community visibility planning.

---

## Available Skills

*(To be populated as skills are built)*

- Facebook event description writer
- Press release drafter
- Recruitment flier content generator
- Event photo caption suggestions

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Writing a Facebook event description for an upcoming pack meeting or outing
- Drafting a press release for a major pack event (Pinewood Derby, Blue & Gold, crossover)
- Creating recruitment flier content for school-night or activities fair
- Writing a post-event recap post for Facebook
- Planning the visibility events calendar for the year
