# the pack Events

Time-bound activities and gatherings that the pack organizes each year. Each event page describes what the event is, when it happens, who's involved, and the tasks needed to make it happen.

Events are organized by category:

| Category | Events |
|---|---|
| [Program](program/) | Pack meetings, Pinewood Derby, Blue & Gold Banquet, and planning conferences |
| [Ceremonies](ceremonies/) | Arrow of Light crossover, charter presentation |
| [Recruitment](recruitment/) | School-night sign-ups, activities fairs, new family orientation |
| [Fundraising](fundraising/) | Annual popcorn sale |
| [Outdoor](outdoor/) | Fall camping, spring hike |
| [Service](service/) | Scouting for Food, caroling, spring service projects |
| [Outings](outings/) | ValleyCats Scout Night and other group outings |

For the full month-by-month planning guide, see the [Annual Calendar]({{ '/roles/annual-calendar/' | relative_url }}).
