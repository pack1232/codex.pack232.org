# Advancement Chair Agent

## Agent Purpose

The Advancement Chair agent is designed to help with advancement tracking, award purchasing lists, ceremony planning, and communications with den leaders about advancement status.

---
audience: adult

## Available Skills

*(To be populated as skills are built)*

- Advancement report generator
- Award purchasing checklist
- Ceremony script drafts
- Den leader advancement reminder

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Generating a list of awards to purchase based on Scoutbook advancement data
- Drafting a reminder to den leaders to update Scoutbook before the pack meeting
- Creating a ceremony script for a crossover or rank advancement ceremony
- Summarizing advancement status across all dens for the committee meeting
