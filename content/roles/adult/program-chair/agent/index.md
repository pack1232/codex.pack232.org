# Program Chair Agent

## Agent Purpose

The Program Chair agent is designed to help with event planning, safety checklists, family communications, logistics for pack activities and camping trips, and service project planning.

> **Note:** This agent combines the capabilities of the former Activities Chair and Service Chair agents.

---
audience: adult

## Available Skills

*(To be populated as skills are built)*

- Event planning checklist generator
- SAFE Checklist template
- Family event communication drafter
- Camping packing list generator
- Service project idea generator
- Service hour report generator

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Building a planning checklist for a specific upcoming event
- Generating a SAFE Checklist for a proposed activity
- Drafting a family communication with event logistics and what to bring
- Creating a camping packing list appropriate for the season and Scout age
- Planning the activity calendar for the upcoming year
- Brainstorming service project ideas appropriate for Cub Scout-age youth
- Building a planning checklist for a specific service event
- Drafting a family communication about an upcoming service project
- Generating a service hour report for submission to the Committee Chair
