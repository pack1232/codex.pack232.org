# Fundraising Chair Agent

## Agent Purpose

The Fundraising Chair agent is designed to help with money-earning application preparation, fundraiser planning, and Scout account communications.

---
audience: adult

## Available Skills

*(To be populated as skills are built)*

- Money-Earning Application drafter
- Fundraiser planning checklist
- Scout account statement generator

---

## Trigger Scenarios

Invoke this agent when you need help with:

- Drafting a BSA Unit Money-Earning Application for a proposed fundraiser
- Planning the logistics of a specific fundraising activity
- Communicating Scout account balances to families
- Reviewing whether a proposed activity requires a money-earning application
